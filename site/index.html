Install in one config

Get a Free Trial key on MCPize, then paste this into Cursor ~/.cursor/mcp.json.

  1. Open mcpize.com/mcp/leaseiq-pro and choose Free Trial.
  2. Copy your API key.
  3. Add the block below and restart Cursor.
{
  "mcpServers": {
    "leaseiq-pro": {
      "url": "https://leaseiq-pro.mcpize.run/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_MCPIZE_API_KEY"
      }
    }
  }
}
